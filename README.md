Student Performance Analysis and Prediction-

About the Project-

This project analyzes student performance using Python, Pandas, NumPy, Matplotlib, Seaborn, and Machine Learning. It explores how study hours, attendance, previous marks, and sleep hours affect students' final marks.

The project also uses Linear Regression to predict the final marks of a student based on the provided details.

Objectives-

- Analyze student academic performance.
- Explore the relationship between study hours, attendance, and final marks.
- Visualize data using graphs and a correlation heatmap.
- Predict students' final marks using Linear Regression.

Technologies Used-

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

Features-

- Data generation and preprocessing
- Exploratory Data Analysis (EDA)
- Missing value checking
- Statistical summary
- Data visualization
- Correlation heatmap
- Linear Regression model
- Prediction of final marks for new students

Machine Learning Model-

Linear Regression is used to predict final marks based on study hours, attendance, previous marks, and sleep hours.

How to Run-

1. Download the "Student_performance_Analysis.ipynb" file.
2. Open "Google Colab" (https://colab.research.google.com/).
3. Upload the notebook.
4. Run the code cells in order.

Project Outcome-

The project demonstrates how data analysis and machine learning can be used to understand student performance and estimate final marks.
